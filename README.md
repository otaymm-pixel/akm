# 🌋 Lava Rush Obby

A 30-stage Roblox obby that climbs higher over a sea of lava. The whole course is
generated by script, so this repo is pure Luau code with no binary place file.

## Features
- **30 stages** in six obstacle types: jump pads, lava-strip walkways, moving
  platforms, spinning lava bars, vanishing tiles, and truss climbs onto narrow beams.
  Each stage is harder than the last.
- **Checkpoints**: you respawn at the highest stage you've reached.
- **Coins**: 3 per stage. They respawn after 15 seconds.
- **Skip Stage** button: spend 25 coins to skip a stage.
- **Winning**: touch the trophy platform to get +1 Win and +50 coins, then start again from stage 1.
- **Leaderboard** with Stage, Coins and Wins, saved through DataStores.
- HUD with a progress bar and pop-up messages.

## How to play it in Roblox Studio
1. Install [Rojo](https://rojo.space/) (the CLI plus the Studio plugin).
2. In this folder, run `rojo serve`.
3. Open a new **Baseplate** place in Studio. Delete the `Baseplate` part and the default
   `SpawnLocation`. Then click **Connect** in the Rojo plugin.
4. Press **Play**.

To keep progress saved while testing in Studio, turn on
*Game Settings → Security → Enable Studio Access to API Services*.

Or build a place file directly: `rojo build -o LavaRushObby.rbxlx`, open it in Studio,
then publish it with *File → Publish to Roblox*.

## Layout
| File | Becomes |
|---|---|
| `src/shared/Config.luau` | `ReplicatedStorage.Shared.Config`: all tuning values |
| `src/server/Main.server.luau` | `ServerScriptService.Server.Main`: gameplay, saving, shop |
| `src/server/MapBuilder.luau` | `ServerScriptService.Server.MapBuilder`: builds the course |
| `src/client/HUD.client.luau` | `StarterPlayerScripts.Client.HUD`: UI and coin spin |

To change the stage count, coin values, skip cost and other settings, edit `Config.luau`.
